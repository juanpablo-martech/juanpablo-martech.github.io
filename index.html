Caso 01 · Web

Una tienda que no deja ir al que no encuentra su producto

Unos 320 productos en cinco mundos que no se parecen entre sí: anime, pop, decoración, religioso y personalizados. Cada mundo necesitaba su propia cara sin multiplicar el trabajo por cinco.

Rol
Dirección, diseño y construcción
Hecho con
Código (HTML, CSS, JavaScript, WebGL) e IA sobre Shopify
  • Una sola plantilla de mundo por variables, construida una vez y vestida para los cinco.
  • Una ruta de escape en tres niveles que lleva al visitante que no encuentra su producto hasta el pedido personalizado.
  • Fondo generativo en WebGL con un velo que se aclara al bajar, para que la marca se sienta sin tapar el catálogo.
  • Descripciones de colección escritas para leerse en el celular.
  • Las herramientas de los casos 03 y 04 también son aplicaciones web que construí, con buscador, base de datos y botones que ejecutan tareas.

La tienda trabaja como un catálogo que lleva a WhatsApp, que es donde cierra el comprador colombiano.

El código detrás de la tienda

La portada abre sobre un fondo generativo en WebGL que se aclara a medida que el visitante baja al catálogo. Este es ese fondo, con el mismo shader de la tienda, corriendo aquí. Mueve el velo para ver la transición.

// Seis paradas de color, bloqueadas a la marca
vec3 ramp(float t){
  vec3 c0 = vec3( 12., 10., 26.)/255.; // índigo
  vec3 c1 = vec3( 22., 34., 86.)/255.;
  vec3 c2 = vec3( 47.,164.,255.)/255.; // azul
  vec3 c3 = vec3(123., 92.,255.)/255.; // morado
  vec3 c4 = vec3(217., 75.,255.)/255.; // fucsia
  vec3 c5 = vec3(236.,212.,255.)/255.; // lavanda
  vec3 c = mix(c0, c1, smoothstep(0., .30, t));
  c = mix(c, c2, smoothstep(.30, .47, t));
  c = mix(c, c3, smoothstep(.47, .65, t));
  c = mix(c, c4, smoothstep(.65, .83, t));
  return mix(c, c5, smoothstep(.83, 1., t));
}

// El ruido deforma al ruido: así respira la malla
vec2 q = vec2(fbm(p + vec2(t*.15, 0.)),
              fbm(p + vec2(5.2, 1.3) - vec2(0., t*.12)));
vec2 r = vec2(fbm(p + 4.*q + vec2(1.7, 9.2) + vec2(t*.1, 0.)),
              fbm(p + 4.*q + vec2(8.3, 2.8) - vec2(0., t*.08)));
float f = fbm(p + 4.*r);
  • La paleta no puede derivar: el verde, el turquesa y el cian quedan fuera por construcción.
  • El fondo es fijo en toda la página y el velo sube de 0 a 90 % al salir de la portada, para que el catálogo se lea blanco iluminado y no blanco plano.
  • Si el teléfono pide reducir el movimiento, el velo queda fijo y no hay animación.

Caso 02 · Automatización

FORMARCA: un equipo de agentes de IA con roles y reglas

Una marca pequeña tiene que auditar su tienda, decidir qué promocionar, buscar imágenes y producir piezas cada semana. Hecho a mano, eso se come el día.

Rol
Arquitectura del sistema y de cada rol
Hecho con
Claude Skills, rutinas programadas, Google Apps Script, n8n y Supabase
  • Cada rol tiene su trabajo, sus reglas y lo que le entrega al siguiente.
  • La auditoría de rendimiento corre sola cada lunes y el cierre de Pinterest, el día 1 de cada mes.
  • Ninguna promoción se publica sin la aprobación del dueño: esa puerta está escrita en el contrato entre roles.
  • Un script de Apps Script arma la estructura de carpetas del sistema en Drive.
  • Para la atención, monté en n8n y Supabase la base de un agente de ventas por WhatsApp, que se enciende cuando el volumen pase de 30 mensajes diarios.

El trabajo se reparte entre roles que se entregan cosas entre sí, y el dueño solo aprueba lo que importa.

La IA y yo: los agentes ejecutan; yo diseñé los roles, las reglas y las puertas de aprobación.

Caso 03 · Contenido a escala

Un motor que lee el producto y diseña la escena

Las primeras imágenes generadas ponían productos distintos en el mismo cuarto, con el mismo mueble y el mismo adorno. Así no se puede publicar todos los días.

Rol
Arquitectura de prompts y control de calidad
Hecho con
Gemini con Nano Banana y herramientas web propias
  • Dejé de nombrar objetos en el prompt, porque lo que se nombra se vuelve la respuesta por defecto.
  • La base fija solo el lugar, la luz y el encuadre; el resto se deriva de diez valores leídos de cada obra.
  • Ninguna pieza sale sin pasar una tarjeta de 5 métricas.
  • Todo vive en plantillas con buscador y bancos de ideas que avisan cuándo se agotan: 11 prompts en cinco tipologías para Pinterest y 11 bases por nicho para Marketplace.

Tres obras, tres cuartos sin un solo mueble en común. El sistema programó 459 publicaciones para cuatro canales, y el perfil de Pinterest pasó de unas 3.800 a 9 mil visualizaciones al mes entre septiembre y noviembre.

La IA y yo: la IA genera la imagen; yo escribí las reglas, medí cada tanda y firmé cada prompt solo cuando funcionó.

Caso 04 · Redacción automatizada

De una sola imagen a la publicación completa

Escribir a mano el título, la descripción, las etiquetas y los mensajes de cada publicación era el cuello de botella para publicar dos veces al día.

Rol
Diseño del asistente y de sus reglas
Hecho con
Gems de Gemini con instrucciones propias
  • El asistente recibe solo la imagen y devuelve título, descripción, precio, campos, etiquetas, los grupos de la ciudad, el mensaje del grupo y la primera respuesta al comprador.
  • Conoce los precios, la fórmula del título, las categorías y las palabras prohibidas.
  • Se revisa solo con 12 puntos antes de entregar.

La redacción de cada publicación pasó de trabajo manual a un paso de revisión.

La IA y yo: el asistente redacta; yo definí qué sabe, qué no puede decir y cómo se revisa.
